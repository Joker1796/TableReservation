# Кочующий стол

Пет-проект для клуба настольных игр. Веб-приложение для бронирования столиков: участники создают заявки, приглашают друг друга, администраторы назначают столы и подтверждают бронирования. Также есть раздел мастерская с фотогалереей.

## Стек

- **Backend:** Laravel 13, PHP 8.3+
- **Frontend:** Vue 3, TypeScript, Inertia.js
- **UI:** Tailwind CSS 4, Reka UI
- **База данных:** SQLite (по умолчанию)
- **Аутентификация:** Laravel Fortify (в т.ч. 2FA), Sanctum (API-токены)

## Установка

```bash
git clone <репозиторий>
cd ClubTableReservation
composer run setup
```

Команда `setup` автоматически: устанавливает зависимости, создаёт `.env`, генерирует ключ приложения, выполняет миграции и собирает фронтенд.

При необходимости отредактируй `.env` (например, сменить драйвер БД).

## Разработка

```bash
composer run dev
```

Запускает одновременно: PHP-сервер, очередь задач, просмотрщик логов и Vite dev-сервер.

## Тесты

```bash
composer run test
```
